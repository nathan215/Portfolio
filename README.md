# Portfolio

Coursework portfolio, 2022: C++ OOP projects and R machine-learning exercises.

## C++ OOP projects (`OOP Learning project 2022/`)

| Project | Description |
|---|---|
| [A Simple Text Processor](<OOP Learning project 2022/A Simple Text Processor>) | Text-processing utilities: character/word counts, global find-and-replace, a shift-cipher encryption, substring counting, and left/right/justified line formatting. |
| [Deque](<OOP Learning project 2022/Deque>) | A linked-list-based Deque (double-ended queue) with `push_back`/`push_front`/`pop_back`/`pop_front`, `size`, `empty`, and `print`. |
| [Dictionary using trie](<OOP Learning project 2022/Dictionary using trie>) | A trie-based dictionary (26-way tree of nodes) supporting create, delete, merge, filter, and manipulate operations on word/meaning entries. |
| [Fast Interger Factorization](<OOP Learning project 2022/Fast Interger Factorization>) | Integer factorization via the Pollard-Rho algorithm; run as `factorize [range_start] [range_end]`. |
| [Multi-type map using Skiplist](<OOP Learning project 2022/Multi-type map using Skiplist>) | A multi-type key-value map (user-defined key/value types and hash function) backed by a Skip List for average O(log n) search, insert, and delete. |
| [Nonogram](<OOP Learning project 2022/Nonogram>) | A command-line Nonogram (Picross) game — print/modify/check the board interactively, or auto-solve it with a DFS-based solver. |
| [Simple Relational Database Management System](<OOP Learning project 2022/Simple Relational Database Management System>) | A C++ RDBMS with CRUD operations, table relationships via foreign keys, transactions, and file-based persistence. |
| [The Lord of the Rings](<OOP Learning project 2022/The Lord of the Rings>) | A command-line RPG on a grid map — collect items, fight monsters, and play as one of three character classes (Warrior, Archer, Mage), built with inheritance/polymorphism. |

## R machine-learning scripts (`Machine Learning/`)

| Script | Description |
|---|---|
| [Bias and Varience trade off.r](<Machine Learning/Bias and Varience trade off.r>) | Simulation comparing the bias-variance tradeoff of linear regression vs. k-NN regression as model complexity (number of predictors, k) varies. |
| [Logistic regression with L2 penalty.r](<Machine Learning/Logistic regression with L2 penalty.r>) | Logistic ridge (L2-penalized) regression fit from scratch via Newton-Raphson, with k-fold cross-validation, checked against `glmnet`. |
